# Дедушкин огород — версия для Unity

Это перенос браузерной игры (папка `game/`) в Unity. Браузерная версия не тронута и продолжает работать.

**Шаг 1 из нескольких:** здесь пока только огород.

## Что уже есть

- огород 72×44 клетки: дом, колодец, ящик для отгрузки, почтовый ящик, пруд, стройплощадки, деревья, кусты, камни, ветки, цветы;
- ходьба клавишами и щелчком мыши (Тёма сам подходит к клетке);
- мотыга, лейка, посадка 10 культур, рост по ночам (без полива вдвое медленнее), сбор урожая;
- урожай выпадает на землю и сам подлетает к Тёме;
- день и ночь, сон у двери дома, утренний отчёт;
- четыре сезона по 12 дней: листва, цветы, трава меняются по дням, зимой снег, протоптанные дорожки и лёд на пруду;
- свет по времени суток и тени, которые идут за солнцем (у дома, колодца, ящика, камней — объёмные);
- инвентарь (I) с ячейками экипировки, ящик для отгрузки (на 10% дешевле рынка), админ-панель (H);
- сохранение (отдельное от браузерной версии).

## Чего пока нет (следующие шаги)

Перекрёсток, рынок, речка и лес; топор, кирка и коса; звуки; телефонное управление.

## Как открыть

1. Установите **Unity Hub**: https://unity.com/download
2. В Unity Hub откройте вкладку **Installs** и установите **Unity 6 LTS** (любая версия 6000.0.x). Модули для сборки под платформы пока не нужны.
3. Скачайте проект с GitHub (ветка `claude/intro-section-overview-lbiuc6`) или обновите свою копию.
4. В Unity Hub: **Projects → Add → Add project from disk** и выберите папку `unity` из репозитория.
5. Откройте проект. Первый запуск занимает несколько минут: Unity импортирует файлы. Если Hub предложит другую версию Unity, выберите установленную Unity 6.
6. Нажмите кнопку **Play** (▶) вверху. Сцену открывать не нужно: игра запускается сама в любой сцене.

## Если что-то не так

- Откройте **Window → General → Console**. Красные строки — ошибки. Скопируйте их текст (или сделайте снимок экрана) и пришлите.
- Если в Console есть ошибка про **Input System** или игра пишет про «Active Input Handling»: откройте **Edit → Project Settings → Player → Other Settings → Active Input Handling**, выберите **Both** и перезапустите Unity.

## Управление

Стрелки или WASD — ходить · Пробел или E — действие · 1–0, −, = — выбрать предмет · I — инвентарь · H — админ-панель · щелчок мыши по клетке — подойти и сделать.

## Как устроен проект

- `Assets/Ogorod/Core/` — правила игры на обычном C# (сезоны, рост, цены, карта огорода). Не зависит от Unity.
- `Assets/Ogorod/Game/` — отрисовка, управление и интерфейс в Unity.
- `Assets/Ogorod/Resources/Ogorod/` — атлас рисунков (`atlas.bytes` — это PNG, `atlasindex.json` — где какой рисунок) и шейдеры тени и света.
- `Tools~/` — вспомогательное, Unity эту папку не видит:
  - `export-atlas.mjs` — заново выгружает рисунки из браузерной версии в атлас: `node unity/Tools~/export-atlas.mjs` (нужны Node и Playwright);
  - `CoreTests` — проверяет правила и то, что карта совпадает с браузерной: `dotnet run` (нужен .NET 8 SDK);
  - `UnityCompileCheck` — проверяет, что скрипты компилируются против библиотек Unity: `dotnet build`.

Рисунки пока черновые, перенесённые из браузерной версии. Когда появятся рисунки из PixelLab, их подключим вместо атласа.
