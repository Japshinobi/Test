# Тестовый стенд: игра в браузере без Godot

Запускает проект `godot/` в Chromium через веб-сборку движка (wasm) и делает снимок экрана.
Нужен, чтобы проверять изменения там, где нет редактора Godot (например, в облачной сессии).

**Ограничения:** в этой сборке движка нет сетевого модуля, поэтому игру вдвоём здесь не проверить
(`serve.py` подменяет сетевые классы заглушками). Свет считается программно (swiftshader),
на телефоне картинка может отличаться.

## Подготовка (один раз)

```
sh setup.sh        # скачивает движок в bin/ (через npm)
```

Нужны Python 3, Node и Playwright с Chromium.

## Запуск

```
python3 serve.py ../../godot &                    # сервер на 127.0.0.1:8765
node run.mjs "http://127.0.0.1:8765/index.html" 20000 shot.png
```

`run.mjs <адрес> <сколько ждать, мс> <файл снимка>`. Переменные: `V=1` — показывать весь вывод
игры, `ACT='<код Playwright>'` — действия перед снимком (клики, клавиши), `PLAYWRIGHT_DIR` — где Playwright.

## Параметры адреса

Сервер правит скрипты на лету по параметрам после `?`:

- `farmtest=1` — дописать в `main.gd` самопроверку из файла (второй аргумент `serve.py`,
  по умолчанию `selftest.example.gd`); она печатает строки `TEST ...`.
- `probe=<скрипт>` — только загрузить `scripts/<скрипт>.gd` и сообщить об ошибках разбора.
- `day=`, `min=` — день и время (минуты от полуночи) при запуске; `yaw=`, `dist=` — камера.
- `sx=`, `sy=` — где появляется герой на огороде.
- `friend=1` — играть за Нину (второго игрока).
- `loc=`, `px=`, `pz=` — подставляются вместо `TESTLOC`/`TESTPOS`, если вписать их во временный тест.
