# Дедушкин огород

Пиксельная игра-ферма в стиле Ragnarok Online: мир в 3D, персонажи и растения — спрайты. Играть можно одному или вдвоём по Wi-Fi.

Тёма получил в наследство от дедушки Матвея старый дом и заросший огород. Нужно растить овощи, продавать урожай на рынке и приводить хозяйство в порядок.

Игра делается на **Godot** (папка `godot/`). Как открыть, играть и собрать APK — в `godot/README.md`.

## Папки

- `godot/` — сама игра. Как открыть — в `godot/README.md`.
- `editor/map-editor.html` — редактор карт: огород, перекрёсток, рынок, речка, лес. Как пользоваться — в `editor/README.md`.
- `android/` — сборка APK для телефона.
- `design/items.xlsx` — база предметов по категориям с характеристиками (для правки и обсуждения).
- `design/weather.xlsx` — база погоды: виды погоды, как культуры переносят заморозки и грозу, правила молнии и снега (для правки и обсуждения).
- `tools/export-atlas.mjs` — собирает все рисунки игры в один атлас (`godot/assets/atlas.png`).
- `tools/web-test/` — тестовый стенд: запускает игру в браузере без Godot (см. его README).
- `HANDOFF.md` — подробная сводка по проекту: цель, что сделано, решения, проблемы, следующие шаги.
- `game/` — **архив**: первая версия игры в браузере. Её больше не развиваем, но `game/sprites.js` остаётся источником рисунков для атласа, а `game/catalog.html` — арт-библией (все рисунки по разделам, палитра, правила стиля).

## Как обновить рисунки

Рисунки пока рисуются кодом в `game/sprites.js`. После правки там соберите атлас заново:

```
node tools/export-atlas.mjs
```

Нужны Node и Playwright с Chromium. Когда появятся рисунки из PixelLab, атлас будет собираться из них.
