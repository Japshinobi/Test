# Куртка Вани — первый слой одежды

Проба слоёв (21.10.2026): зелёная куртка отдельным слоем поверх основы Вани (`../vanya-base/v5/`), 8 направлений.

- `dressed/` — Ваня в куртке, как его нарисовал PixelLab (`edit-image-pixen`, по 1 генерации на сторону; `jacket_dir.py` — описания для вида спереди, сбоку и сзади).
- Слой = пиксели, заметно отличающиеся от основы (`layer_tool.py`), только в зоне тела — ряды 20–46 (от плеч до бёдер), чтобы не цеплять ноги.
- `jacket_tone.py` — один оттенок зелёного во всех сторонах: ИИ красил куртку то бирюзовой, то серо-зелёной.
- Готовые слои — в игре: `godot/assets/chars/vanya/jacket/<сторона>.png`.
- `sheet.png` — по столбцам 8 сторон; ряды: основа, ИИ-куртка, слой, основа + слой. `ingame.png` — снимок со стенда.
