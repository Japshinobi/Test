# Шаблоны локаций

Карта локации — картинка PNG, где **один пиксель — одна клетка**. Цвет пикселя означает, что стоит в клетке.

- `farm.png` — огород, 72×44 клетки. **Этот файл и нужно править.**
- `farm-preview.png` — та же карта, увеличенная, с сеткой и номерами клеток. Только для просмотра.
- `legend.png` — что означает каждый цвет.

## Как править

1. Откройте `farm.png` в редакторе: Paint, Piskel (piskelapp.com, прямо в браузере) или Pixel Studio на телефоне.
2. Сильно увеличьте картинку и рисуйте карандашом толщиной 1 пиксель. Не используйте заливку с размытием, кисти и сглаживание.
3. Берите цвета точно из легенды: в редакторе можно ввести код цвета, например `#4caf50`.
4. Сохраните в **PNG** (не JPG: JPG смазывает цвета).
5. Пришлите картинку и в сообщении допишите то, что не передать цветом.

Если нужного цвета в легенде нет, возьмите любой новый и напишите, что он означает.
Размер картинки можно менять: это меняет размер локации.

## Легенда

| Цвет | Код | Что это |
|---|---|---|
| зелёный | `#4caf50` | трава |
| светло-зелёный | `#a5d66b` | трава с цветами |
| песочный | `#e6c88c` | тропинка |
| синий | `#2f7fe0` | вода |
| тёмно-зелёный | `#1e5a28` | дерево |
| почти чёрный зелёный | `#0b2e12` | большой дуб (3×3 клетки) |
| оливковый | `#8a9a2e` | куст |
| серый | `#8c8c8c` | камень |
| коричневый | `#8b5a2b` | ветки |
| оранжевый | `#f0902a` | место под постройку |
| красный | `#d03030` | дом (закрасить всю площадь) |
| тёмно-красный | `#7a1010` | дверь дома |
| бирюзовый | `#30c8d8` | колодец |
| жёлтый | `#f0e040` | ящик для продажи |
| синий-фиолетовый | `#4040c0` | почтовый ящик |
| розовый | `#f0a0d0` | табличка |
| фиолетовый | `#a040e0` | выход в другую локацию |
| чёрный | `#000000` | непроходимо (стена, обрыв) |
