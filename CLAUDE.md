# CLAUDE.md — «Дедушкин огород»

Читать в начале каждой сессии. Подробности — в базе знаний `knowledge/` (оглавление: `knowledge/README.md`). Общий обзор проекта — `HANDOFF.md`.

## Что за игра

Пиксельная игра-ферма для Android на **Godot 4** (папка `godot/`), в стиле Ragnarok Online.
- Мир объёмный (земля, вода, дом), а персонажи, растения и предметы — пиксельные спрайты, повёрнутые к камере.
- Сюжет: Тёма получил от дедушки Матвея старый дом и заросший огород, растит урожай и продаёт его на рынке.
- Пять локаций, 10 культур, 4 сезона по 12 дней, рынок с торговцами, инструменты.
- Игра вдвоём по Wi-Fi: огород и деньги общие, инвентарь у каждого свой.
- Проект некоммерческий. Цель — попробовать, а при удаче дорасти до уровня Stardew Valley / Sun Haven.

## Правила работы с владельцем

- **Отвечать по-русски, простыми словами.** Владелец не программист и ведёт разработку через ИИ.
- **Просьбы владельца выполнять сразу. Свои идеи — сначала обсудить** и делать только после согласия. Даже маленькое «заодно поправлю».
- **APK собирать только по команде владельца** (когда он скажет, что будет тестировать). Не после каждого изменения.
- **Напоминать о тесте на двух телефонах** перед изменениями в игре, пока владелец не скажет, что тест проведён. Новые функции вдвоём ещё не проверены.
- **Ничего не придумывать за владельца** в системах, которых ещё нет (НПЦ, диалоги, события, еда, одежда): сначала вопросы из рецептов.
- Коммитить в рабочую ветку, PR — только по просьбе.

## Главные технические решения

Подробно: `knowledge/decisions/architecture.md`, `network.md`, `data.md`.

- **Код:**
  - GDScript, без `class_name`: скрипты подключаются через `const X := preload("res://scripts/x.gd")`;
  - сцена и интерфейс строятся кодом (`main.tscn` — один узел со скриптом `main.gd`);
  - тексты для игрока — по-русски прямо в коде.
- **Рендер GL Compatibility** (для слабых телефонов). 1 клетка = 1 единица 3D, X — восток, Z — юг. Спрайты: `Sprite3D`, `BILLBOARD_FIXED_Y`, `pixel_size = 1/16`, растяжение по высоте `STRETCH = 1.25`, без освещения, подкрашиваются по времени суток (`TINT`).
- **Игра вдвоём — «хозяин решает»:**
  - любое изменение мира — только через `farmnet.request(action, args)` → у хозяина `_host(...)` → рассылка `_all` / `_to` методами `net_*`;
  - так работает и в одиночной игре;
  - интерфейс сам ничего не меняет.
- **Общее и личное:** общее — деньги, грядки, ящик, предметы на земле, изменения карт, день. Личное — инвентарь, вода в лейке, локация.
- **Карты** — `godot/maps/<id>.json`, их правит редактор `editor/map-editor.html`. Каталог земли и объектов — `godot/data/objects.json` (читают игра и редактор).
- **Изменения карт** (срубили, скосили) хранятся отдельно как **mods** по клеткам, файлы карт игра не меняет.
- **Сохранение** `user://save.json` пишет только хозяин; инвентари гостей — по постоянному номеру из `user://player.cfg`. Новое поле сохранения — всегда через `.get(поле, умолчание)`.
- **Рисунки** пока рисуются кодом в `game/sprites.js` → атлас `godot/assets/atlas.png` собирает `node tools/export-atlas.mjs`. Новый спрайт = рисунок в `sprites.js` + имя в `export-atlas.mjs` + пересборка.
- **Предмет** — строка `"вид:ключ"` (`tool:hoe`, `seed:radish`, `prod:radish`, `res:wood`). Описаны в `godot/scripts/farm.gd` (`TOOLS`, `CROPS`, `RES`, `TRADERS`).

## Файлы игры (`godot/scripts/`)

- `main.gd` — ввод, камера, ходьба, время, свет, переходы, сеть.
- `farm.gd` — правила и предметы.
- `farm_net.gd` — действия игроков, рассылка, сохранение.
- `world.gd` — 3D-картинка локации.
- `location.gd` — карта и mods.
- `hud.gd` — интерфейс.
- `avatar.gd` — персонаж; `atlas.gd` — атлас; `sfx.gd` — звуки.

## Как проверять изменения

Подробно: `tools/web-test/README.md` и раздел «Как проверить» в каждом рецепте.

1. **Тестовый стенд** (игра в браузере без Godot):

   ```
   sh tools/web-test/setup.sh                      # один раз: скачать движок
   cd tools/web-test && python3 serve.py ../../godot [свой_тест.gd] &
   node run.mjs "http://127.0.0.1:8765/index.html?farmtest=1" 25000 shot.png
   ```

   - Самопроверка — функция `_selftest()` (образец `selftest.example.gd`), печатает строки `TEST ...`.
   - Снимок `shot.png` смотреть глазами.
   - Ошибки разбора скриптов видны в выводе.
   - **Сеть на стенде не работает.**
2. **Игра вдвоём** — только в Godot на компьютере (2 экземпляра) или на двух телефонах у владельца.
3. **Карты** — открыть в редакторе, пересохранить, `git diff` должен показывать только нужное.
4. После правок проверять: нет ли в выводе «Нет спрайта», ошибок GDScript, строк `SCRIPT ERROR`.
