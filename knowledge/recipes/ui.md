# Рецепт: изменение интерфейса

## Когда использовать

- «Добавь кнопку / окно / надпись», «Сделай шрифт крупнее», «Перенеси часы».
- «Поменяй текст справки или вступления».
- Новое окно для новой системы (торговец, письма, крафт…).
- Изменения панели быстрого доступа и инвентаря.

## Что уже есть в игре

Весь интерфейс — `godot/scripts/hud.gd`, строится кодом в `setup(p_main)`. Сцен `.tscn` для интерфейса нет.

- **Постоянные панели:**
  - слева вверху — «Игра вдвоём»: `host_btn`, `ip_edit`, `join_btn`, `leave_btn`, `status`; сворачивается;
  - справа вверху — часы `clock`, деньги и лейка `money_label`, кнопки «Инвентарь», «Справка», «Админ», надпись `sleepers_label`;
  - внизу — «В руках: …» (`tool_label`), панель быстрого доступа (`belt_box`, ячейки `SlotButton`, стрелки `ArrowButton`), строка подсказки;
  - всплывающее сообщение `toast(text)` (2.8 с);
  - затемнение при переходе `set_fade(a)`.
- **`refresh()`** вызывается каждый кадр из `main.gd` → `_process`. Панель перестраивается, только когда меняется «подпись» состояния (`_belt_sig`).
- **Окна (диалоги):**
  - `_open(kind, title, width)` закрывает предыдущее окно, рисует затемнение (`DropZone`) и панель и возвращает `VBoxContainer`, куда класть содержимое;
  - помощники: `_text(v, text, size)`, `_buttons(v)` (ряд кнопок по центру), `_button(parent, text, action)`, `_item_row(v, icon, text)` (иконка, текст и место для кнопок);
  - `close_dialog()`; `dialog_kind` — какое окно открыто;
  - `is_busy()` — открыто окно: герой стоит, тапы по миру не работают (`main.gd` → `_tap`, `_process`).
- **Готовые окна:**
  - `show_message(title, text)`;
  - `ask_sleep()`, `update_sleep(ids)`;
  - `show_morning(m, note)`;
  - `open_intro()`, `open_help()`, `_confirm_restart()`;
  - `open_admin()`;
  - `open_ship()`;
  - `open_trader(who, tab)`;
  - `open_inventory()`;
  - `_confirm_erase(index)`;
  - меню предмета `open_item_menu(index)` (`PopupMenu`).
- **Обновление окна при изменении данных** — `refresh_farm()`: по `dialog_kind` заново открывает `ship`, `trader` или перерисовывает сетку инвентаря. Его вызывают `net_inv` и `net_my_inv`.
- **Оформление** — `_theme()`:
  - синие панели `Color(0.11, 0.15, 0.29, 0.92)` с золотой рамкой `#d9b45a`;
  - кнопки `#2c4a86`, текст `#f4e6c0`, заголовки окон `#f0cf7a`;
  - размер шрифта по умолчанию 18;
  - выделение — `_box(Color("#4a63a8"), Color("#f0cf7a"), 3)`;
  - надписи поверх мира — `_outlined_label(size)` (с обводкой).
- **Ячейки инвентаря** — класс `SlotButton`: тап — взять в руки, перетаскивание (`_get_drag_data` / `_drop_data`) — `request("move")`, долгое нажатие 0.55 с или правая кнопка — меню. Размер `SLOT := 58`.
- **Экран:** окно 1280×720, `stretch/mode="canvas_items"`, `aspect="expand"` (`project.godot`). На телефоне интерфейс масштабируется целиком.
- **Клавиши** обрабатывает `main.gd` → `_unhandled_input`: пробел, 1–0, I/Tab, H. Q/E — в `_rotate_keys`.

## Какие файлы затрагиваются

- `godot/scripts/hud.gd` — почти всегда только он.
- `godot/scripts/main.gd` → `_unhandled_input` — новая клавиша.
- `godot/scripts/farm_net.gd` — если окно что-то меняет в мире: новое действие в `_host` (см. [[network]]).
- `godot/scripts/farm_net.gd` → `act` — если окно открывается тапом по объекту.

## Шаги по порядку

### Новое окно

1. Функция `open_<что>()` в `hud.gd`, внутри — `var v := _open("<kind>", "Заголовок", ширина)`, затем `_text`, `_item_row`, `_buttons` + `_button`. Внизу — кнопка закрытия (`close_dialog`).
2. Кнопки, меняющие мир, вызывают **только** `main.farmnet.request("<действие>", [...])`. Свои данные окно берёт из `main.farmnet.my_inv`, общие — из `main.farmnet.farm`.
3. Если окно показывает данные, которые меняются по сети, добавить ветку в `refresh_farm()` по его `kind`.
4. Как открывать: кнопка в верхней правой панели (`_button(row2, ...)` в `setup`), тап по объекту (`farm_net.gd` → `act`) или клавиша (`main.gd`).
5. Если окно должно быть доступно только хозяину — проверять `main.farmnet.is_host()`, как в `open_admin` и `open_help`.

### Изменить текст

- Справка и вступление: константа `HOW`, `open_intro`, `open_help`.
- Утро: `SEASON_TEXT` и `show_morning`.
- Подсказка внизу экрана: строка `hint.text` в `setup`.
- Сообщения действий: в `farm.gd` (`use` возвращает `msg`) и `farm_net.gd` (`act`, `_strike`, `_host`).

### Новая постоянная надпись или кнопка

Добавить в `setup` рядом с похожей, обновлять в `refresh()`. Если обновление тяжёлое — по примеру `_belt_sig`: перестраивать только при изменении.

## Как проверить

- **Стенд** `tools/web-test/`: самопроверка открывает окно (`hud.open_inventory()`, `hud.open_trader("veg")`, `hud.open_admin()`…), ждёт `await get_tree().create_timer(1.0).timeout`. Снимок `shot.png` — посмотреть глазами (инструментом Read).
- **Нажатия:** переменная `ACT` для `run.mjs` — код Playwright, например `await page.mouse.click(640, 400)`. Перетаскивание в стенде работает только с медленными шагами мыши (`page.mouse.move(x, y, {steps: 20})`) — см. [[lessons]].
- **Размер экрана:** `run.mjs` снимает 1280×720. Узкий экран телефона проверять отдельно: в `run.mjs` поменять `viewport`. Длинные строки должны переноситься (`autowrap_mode`), а не уходить за край.
- **Глазами:** текст по-русски, без обрезанных слов; крупные кнопки (пальцем на телефоне попадать); окно не перекрывает панель быстрого доступа без нужды.

## Подводные камни

- **Окно одно:** `_open` закрывает предыдущее. Окно поверх окна (подтверждение) делается так: закрыть → открыть подтверждение → после ответа открыть прежнее заново (`_confirm_erase` с `reopen`).
- **Затемнение принимает брошенные предметы.** У `CenterContainer` в `_open` стоит `MOUSE_FILTER_IGNORE`. Если поменять — перестанет работать «выбросить, перетащив за окно» (см. [[lessons]]).
- **Сообщение `toast`** привязано к верхней полосе экрана (`PRESET_TOP_WIDE`, отступы 420 и `offset_top = 215`). При переделке проверить, что оно видно и на узком экране.
- **Сеть:**
  - у гостя данные приходят с задержкой, поэтому окно должно перерисовываться через `refresh_farm()`, а не считать результат заранее;
  - деньги общие: у гостя кнопки «купить» блокируются по `farm.money`, которые прислал хозяин;
  - имена игроков — только «Тёма» (id 1) и «Друг» (`_player_name`).
- **Каждый кадр:** `refresh()` вызывается 60 раз в секунду — не создавать в нём узлы без проверки «изменилось ли».
- **Не забывать `is_busy()`:** пока открыто окно, герой не ходит. Окно без кнопки закрытия «запирает» игрока.
- **Новые клавиши** не должны срабатывать, пока вводится текст (`_typing()`) или открыто окно (`hud.is_busy()`).
